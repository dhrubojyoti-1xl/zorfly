# Operational Runbooks

Runbooks will be added with the infrastructure they operate. Every page-worthy
alert must link to an owned, tested runbook covering:

- symptoms and customer impact;
- safe diagnostic steps;
- containment and recovery;
- escalation and communication;
- rollback or failover;
- verification and evidence preservation;
- post-incident follow-up.

Runbooks must not contain credentials or sensitive customer data.
