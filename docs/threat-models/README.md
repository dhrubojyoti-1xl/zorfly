# Threat Models

Threat models are required before implementation for:

- identity, sessions, and authorization;
- tenant isolation;
- AI prompts, tools, agents, and retrieval;
- uploads, generated images, and SVG rendering;
- public APIs and webhooks;
- administrative and support access;
- deployment and software supply chain.

Each model identifies assets, trust boundaries, threat actors, abuse cases,
controls, residual risk, owners, and review dates.
